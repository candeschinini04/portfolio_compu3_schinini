Sitio web personal de portfolio desarrollado como trabajo práctico para la materia Computación 3, 
correspondiente a la carrera de Diseño y Comunicación Visual en la Universidad Nacional de Lanús (U.N.L.a).
Estructura del proyecto
portfolio/
├── index.html          # Página principal
├── carrusel.html       # Galería de trabajos universitarios
├── contacto.html       # Página de contacto
├── estilos.css         # Hoja de estilos principal
├── img/                # Imágenes del sitio
└── font/               # Tipografías

Páginas
index.html — Página principal con presentación, proyectos destacados y sección de contacto.
carrusel.html — Galería interactiva con trabajos universitarios, navegación por flechas, thumbnails y swipe táctil.
contacto.html — Formulario de contacto.

Responsive
El sitio cuenta con un @media query para pantallas de hasta 600px en el index.html, el area mayor desarrollada son las ods primaeras pantallas (portada y area sobre mi).
El archivo carrusel.html tiene un responsive efectivo de forma nativa, ya que fue construido desde el inicio con unidades 
flexibles, max-width y propiedades como flex-wrap.

Tamaño de mi pantalla 
Resolución: 1680 x 1050 px
Orientación: horizontal (landscape)

Editor de código
Visual Studio Code

Tipografías
Raleway — Google Fonts (usada en index.html)
Playfair Display y DM Mono — Google Fonts (usadas en carrusel.html)
Truculenta — fuente local (archivo .ttf)
